# GeneScribe

GeneScribe is a tool for fact extraction and gene summarization using Large Language Models (LLMs). It uses a two-step workflow:

1. **Fact extraction:** structured prompt-based extraction of gene-fact pairs from publications, each linked to supporting text from the source paper (evidence sentences) to provide provenance.
2. **Gene summary generation:** synthesis of the extracted facts into concise, modular gene summaries, either de novo for genes that lack a gene summary or as an update to an existing Alliance gene summary.

## Code (`src/`)

- `GeneScribe_fact_extraction.ipynb`: Step 1 (Fact extraction), extracts gene-fact pairs and their evidence sentences from the full text of publications.
- `GeneScribe_gene_summary_generation_NoExistGeneDesc.ipynb`: Step 2 (Gene summary generation), generates a de novo gene summary for genes that lack a gene summary.
- `GeneScribe_gene_summary_generation_ExistGeneDesc.ipynb`: Step 2 (Gene summary generation), updates the existing Alliance gene summary of genes with a gene summary by incorporating the newly extracted facts.

## Data

- `data/`: `data_pairs_20251002.json` contains the extracted gene facts and the existing Alliance gene summaries for each gene (the input to Step 2), and `extracted_data_20251002.csv` lists all extracted gene-fact pairs with their evidence sentences from the original publications.
- `gene_description/`: the gene summaries generated by GeneScribe, in `no_desc_2026/` (genes that lack a gene summary) and `incomplete_desc_2026/` (genes with an existing gene summary that were updated).
